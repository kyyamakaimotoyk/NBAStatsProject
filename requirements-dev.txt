#   - Dockerfile.pipeline installs `-r requirements-pipeline.txt`, which pulls in

#     be part of the cloud image.

# serves the multi-GB CUDA build. Install the CPU wheel by hand (matches the
# Dockerfile.pipeline pin):
#   pip install torch==2.9.1 --index-url https://download.pytorch.org/whl/cpu
# (GPU users: pick your build at https://pytorch.org/get-started/locally/ instead.)
#
# NOTE: keep this file pure ASCII -- pip decodes requirements files with the
# system locale (cp932 on Japanese Windows), so non-ASCII bytes break installs.
